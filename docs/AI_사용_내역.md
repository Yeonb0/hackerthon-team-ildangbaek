# AI 활용 내역

**skinteller**는 사용자의 얼굴 이미지를 기반으로 피부 상태를 정량적으로 분석하고, 분석 결과를 바탕으로 개인 맞춤형 성분 및 제품 추천을 제공하는 AI 기반 피부 분석 서비스입니다.

본 서비스는 단순히 생성형 AI에 분석을 의존하는 방식이 아니라, **컴퓨터 비전 기반 피부 분석 기술과 OpenAI 이미지 인식 모델을 결합한 하이브리드 분석 구조**를 적용하였습니다.

이를 통해 이미지 처리 기반의 객관적인 수치 분석과 AI의 이미지 이해 능력을 함께 활용하여, 보다 안정적이고 사용자 친화적인 피부 분석 경험을 제공하도록 설계하였습니다.

AI는 다음 네 가지 핵심 영역에서 활용되었습니다.

---

## 1. AI 기반 피부 점수 정교화

skinteller는 얼굴 이미지에서 **트러블, 홍조, 모공, 색소침착**의 네 가지 주요 피부 지표를 분석합니다.

먼저 OpenCV 기반 이미지 분석을 통해 피부 영역의 밝기, 색상 변화, 특징 패턴 등을 정량적으로 분석하여 1차 피부 점수를 산출합니다.

하지만 실제 피부 상태는 촬영 환경, 조명, 이미지 품질 등에 영향을 받을 수 있기 때문에 단순한 이미지 처리만으로는 한계가 존재합니다.

이를 보완하기 위해 1차 분석 데이터와 원본 이미지를 AI 모델에 함께 전달하여, AI가 이미지 전체의 맥락과 시각적 특징을 종합적으로 검토하도록 구현하였습니다.

즉, 기존 이미지 처리 방식의 정량적 분석 결과에 AI의 이미지 이해 능력을 결합하여 **보다 실제 사용자 환경에 가까운 피부 점수 보정 과정**을 구축하였습니다.

또한 AI 서비스 장애나 네트워크 오류 상황에서도 핵심 분석 기능이 유지될 수 있도록, AI 결과에 전적으로 의존하지 않는 **Fallback 구조**를 적용하였습니다. AI 호출 실패 시 기존 분석 엔진에서 산출한 점수를 활용하여 서비스 안정성을 확보하였습니다.

---

## 2. AI 기반 피부 상태 인사이트 생성

단순한 숫자 형태의 피부 점수만으로는 사용자가 자신의 피부 상태를 직관적으로 이해하기 어렵기 때문에, 분석 결과를 기반으로 개인화된 피부 상태 코멘트를 제공합니다.

AI는 이미지를 분석하는 과정에서 확인한 피부 특징과 산출된 지표를 기반으로 사용자가 이해하기 쉬운 자연어 설명을 생성합니다.

이를 통해 "현재 어떤 피부 고민이 주요하게 나타나는지", "어떤 방향으로 관리하면 좋은지"를 사용자가 쉽게 파악할 수 있도록 하였습니다.

또한 AI에게 생성 기준을 사전에 정의하여,
- 의료적 진단으로 해석될 수 있는 표현 제한
- 긍정적이고 친근한 사용자 경험 유지
- 40~70자 내외의 간결한 설명 생성

등의 가이드라인을 적용하였습니다.

실제 분석 근거가 부족한 상황에서는 AI가 임의로 내용을 생성하지 않도록 제한하고, 테스트 데이터 또는 AI 호출 실패 상황에서는 코멘트를 제공하지 않는 방식으로 신뢰성을 확보하였습니다.

---

## 3. AI 기반 맞춤 제품 추천 설명 생성

제품 추천 과정에서는 AI가 임의로 제품을 선택하지 않습니다.

사용자의 피부 분석 결과와 성분 데이터를 기반으로 구축된 추천 로직이 우선적으로 적합한 제품을 선정하며, AI는 이후 단계에서 해당 추천 결과를 사용자 관점에서 이해하기 쉬운 설명으로 변환하는 역할을 수행합니다.

이를 통해 추천 과정에서는 일관성과 신뢰성을 유지하고, 설명 과정에서는 AI의 자연어 생성 능력을 활용하여 개인화된 추천 경험을 제공합니다.

또한 여러 제품에 대한 설명이 필요한 경우 제품별로 개별 요청을 보내는 방식이 아닌, 여러 제품 데이터를 한 번에 처리하는 **Batch 기반 AI 호출 구조**를 적용하여 API 호출 비용과 처리 시간을 최적화하였습니다.

AI 설명 생성에 실패하더라도 추천 로직 자체는 독립적으로 동작하도록 설계하여 서비스 품질과 안정성을 유지하였습니다.

---

## 4. AI 기반 성분별 피부 관리 가이드 생성

사용자가 특정 성분 정보를 확인할 때, 단순한 성분 설명을 넘어 현재 피부 상태와 연관된 맞춤 관리 팁을 제공합니다.

해당 기능은 단순 데이터 조회 방식으로는 생성하기 어려운 개인화된 설명 영역이므로 AI를 활용하였습니다.

다만 생성형 AI의 특성상 근거 없는 정보가 생성될 가능성을 고려하여, AI에게 전달하는 입력 데이터를 제한적으로 구성하였습니다.

AI에는 실제 분석 과정에서 확인된 피부 지표, 관련 성분 정보, 해당 성분이 영향을 준 분석 근거만 제공하며, 전달된 정보를 벗어난 추론이나 의료적 판단을 생성하지 않도록 제어하였습니다.

또한 충분한 분석 근거가 확보되지 않은 항목은 AI 생성 대상에서 제외하여, 불확실한 정보를 사용자에게 제공하는 것을 방지하였습니다.

# AI 활용 설계 원칙

skinteller는 AI를 모든 판단을 대신하는 도구로 사용하는 것이 아니라, **분석 엔진의 정확도와 사용자 경험을 향상시키는 보조 지능 계층**으로 활용하였습니다.

주요 설계 원칙은 다음과 같습니다.

- **Hybrid AI Architecture**
  - 이미지 처리 기반 정량 분석과 AI 이미지 이해 모델을 결합하여 객관성과 맥락 이해를 동시에 확보하였습니다.

- **AI Dependency 최소화**
  - 핵심 분석 및 추천 로직은 자체 알고리즘으로 처리하고, AI는 결과 보정 및 설명 생성 역할을 담당하도록 분리하였습니다.

- **근거 기반 AI 생성**
  - AI에게 제공하는 입력 데이터를 분석 결과 기반으로 제한하여, 환각(Hallucination) 발생 가능성을 최소화하였습니다.

- **서비스 안정성을 고려한 Fallback 구조**
  - AI API 장애 상황에서도 기본 분석 기능이 유지되도록 설계하여 안정적인 서비스 운영이 가능하도록 구현하였습니다.

이를 통해 skinteller는 단순 AI 챗봇 형태가 아닌, **피부 데이터 분석 기술과 생성형 AI를 결합한 개인 맞춤형 피부 관리 플랫폼**을 목표로 설계하였습니다.
