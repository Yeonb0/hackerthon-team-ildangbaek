# Architecture Decision Records

아키텍처 · 정책 결정을 기록하는 곳입니다. 결정을 바꿀 때는 **기존 ADR을 수정하지 않고 새 ADR을 추가**하고,
기존 ADR의 상태를 `대체됨`으로 바꾸며 새 번호를 가리킵니다. (`CLAUDE.md` — Architecture Decisions)

## 상태 정의

| 상태 | 의미 |
| --- | --- |
| `제안` | 작성자가 제안한 상태. **팀 합의 전이므로 이 결정에 의존하는 코드를 머지하면 안 된다.** |
| `수락` | 팀이 합의한 결정. 구현·문서가 이 결정을 따른다. |
| `대체됨` | 이후 ADR이 이 결정을 대체함. 어느 ADR이 대체하는지 본문에 명시한다. |

## 작성 규칙

1. 파일명은 `NNNN-제목.md` (4자리 일련번호).
2. ADR은 **결정과 그 근거**를 기록한다. 제품·기술 정본 문서(`기능명세서.md`, `api_명세서.md`, `ERD.md`,
   `공통응답포맷_예외처리코드.md`)를 대체하지 않는다. 결정이 수락되면 해당 정본 문서도 **같은 작업 단위에서** 갱신한다.
3. `SCRATCHPAD.md`에만 결정을 남기지 않는다. 그것은 임시 컨텍스트다.
