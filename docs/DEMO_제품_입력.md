# 데모용 올리브영 기초 제품 입력

- **category**는 다음 중 하나만 사용: `TONER`, `LOTION`, `ESSENCE`, `SERUM`, `AMPOULE`, `CREAM`, `GEL`, `BALM`, `OIL`, `SUNCREAM`, `CLEANSING`, `MASK`
